## Near UI Panel
Near UI Panel
Created a blue-coloured panel.
Represents quick-access controls and frequently used options.
Positioned closer to the user

## Middle UI Panel
Created a pink-coloured panel.
Represents information panels and application controls.
Positioned in the middle viewing area.

## Far UI Panel
Created a purple-coloured panel.
Represents notifications and distant information.
Positioned farther from the user.

## Design Approach
The interface uses different colours to distinguish the three spatial zones. Panel positions and sizes are arranged to make the interface easier to understand.

# OmniSpace Design Progress
Today, I worked on the OmniSpace spatial UI layout using Spline. I created a large background panel and three interface panels: Near UI, Middle UI and Far UI. I adjusted their positions, sizes and colours to represent different spatial viewing distances. This is a conceptual 3D design for the OmniSpace project.
