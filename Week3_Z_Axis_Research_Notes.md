# Week 3 – Z-Axis Logic Notes

## Objective
To understand how virtual UI panels are positioned at different distances from the user in a spatial environment.

## 1. Near, Middle and Far UI Positioning
Near panels are used for quick actions and frequently used controls.
Middle panels display the main information and content.
Far panels display supporting information that does not need frequent interaction.

## 2. UI Scaling
UI elements should be scaled according to the user's viewing distance. Text and buttons should remain readable and easy to interact with.

## 3. Depth Layering
The foreground contains active controls, the middle layer contains main content, and the background contains supporting information.

## 4. User Comfort
UI panels should be placed at comfortable viewing positions. Users should not need to move their head or hands excessively.

## Conclusion
This research helped me understand distance-based UI positioning, scaling, depth layering, readability and user comfort in spatial interfaces.
