Week 3 – OmniSpace Spatial UI Design and Prototyping

1. Project Overview
This week, I worked on the OmniSpace spatial dashboard using Figma and Spline. The main objective was to create a spatial user interface and demonstrate how the dashboard changes according to viewing distance.

2. Work Completed
Created the OmniSpace spatial dashboard design in Figma.
Imported the dashboard image into Spline.
Created a 3D dashboard panel.
Configured Base State, Near State and Far State.
Adjusted the dashboard scale for Near and Far viewing conditions.
Added distance-based events and transition actions.
Used Ease In Out transition settings.
Opened Preview mode to inspect the dashboard.
Exported the final dashboard image in PNG format.

3. Spatial Interaction States
Base State
Displays the normal dashboard layout.
Near State
Displays a slightly enlarged dashboard for closer viewing.
Far State
Displays a slightly reduced dashboard for farther viewing.
