# OmniSpace — Week 1 Design & Prototyping

## 1. Project Overview
OmniSpace is a spatial workspace concept focused on creating an organized and interactive digital working environment.

This folder contains the initial design and prototyping work completed for Week 1.

## 2. Week 1 Objectives
- Create initial low-fidelity UI designs.
- Explore the layout and structure of the workspace interface.
- Develop an initial 3D workspace prototype.
- Establish a foundation for future design iterations.

## 3. Low-Fidelity UI Designs
Five low-fidelity screens were created to explore the initial interface layouts and visual structure.

These screens represent early-stage design concepts that can be refined based on feedback and evaluation.

**Folder:** `Low-Fidelity/`

## 4. 3D Workspace Prototype
An initial 3D workspace prototype was created using Spline.

The prototype includes:
- A main workspace surface.
- A main panel.
- Left and right side panels.
- Basic lighting and spatial arrangement.

**Folder:** `Spline-Prototype/`

## 5. Tools Used
- Figma — UI design.
- Spline — 3D workspace prototyping.
- GitHub — Version control and project documentation.

## 6. Contribution
**Area:** UI Design and Prototyping

The contribution includes the creation of initial low-fidelity interface designs, exploration of the workspace layout, development of a basic 3D prototype, and organization of design deliverables.
